## 🛠️ Setup Notes — Activating the 3D & Snake Animations

These two effects are generated by GitHub Actions running on your own repo, so they need a tiny one-time setup:

**1. Snake game animation**
- Create a repo named exactly `Duranda-Abeysinghe` (your username) if you don't have one already — this is your special "profile repo."
- Add a workflow file `.github/workflows/snake.yml` using the `Platane/snk` action. It regenerates the SVG on a schedule and commits it to an `output` branch.
- Point the `<img>` src in this README at that generated SVG (already done above).

**2. 3D contribution calendar**
- In the same profile repo, add a workflow using `yoshi389111/github-profile-3d-contrib`. It runs daily, reads your contribution graph, and renders it as an isometric 3D SVG.
- It writes the SVG to a `profile-3d-contrib/` folder on your `main` branch (already linked above).

If you'd rather skip the Action setup, I can swap those two sections back to static images so everything renders immediately with zero configuration — just say the word.
